# Calculator App 🧮

A simple calculator application created as a learning project.

## 📌 About
This project is a basic calculator application developed for learning and practicing programming. It is designed to perform simple mathematical calculations with a clean and easy-to-use interface.

## ✨ Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Simple and user-friendly interface

## 🎯 Purpose
This application was created for educational purposes to improve programming skills and understand the basic concepts of application development.

## 🛠️ Built With
- Java script, CSS, HTML
- VS CODE

This project is part of my learning journey and may be updated with new features in the future.
